# BunkSmart Architecture

## Stack

- Framework: Expo SDK 58, React Native, TypeScript strict mode
- Routing: Expo Router
- Backend: Supabase (Auth and Postgres)
- Distribution: Expo Go for development and EAS Build for installable Android APK

`ROUTES_DIR` is `src/app`.

## Shared Auth Components

- `BrandMark`, `AuthLayout`, `TextField`, `FormError`, and `LinkRow` in `src/components/ui/` form the shared shell for `(auth)/login` and `(auth)/signup`.
- `AuthLayout` keeps keyboard avoidance, focused-field scrolling, an optional 44 by 44 top-left back button, and bottom footer alignment consistent across screens without duplicating layout styles.
- `TextField` integrates with `AuthLayout` focus scrolling, exposes password visibility toggling, reports disabled state and alert errors to screen readers, and supports Android autofill hints (`name`, `username`, `current-password`, `new-password`).
- Both `(auth)/login` and `(auth)/signup` keep all text input state local so typing never triggers context updates. Inside `(auth)`, Login to Sign up pushes and pops with the native `slide_from_right` transition and swipe back gesture (`src/app/(auth)/_layout.tsx`), while `RootNavigator` (`src/app/_layout.tsx`) switches between `(auth)` and `(tabs)` with a native 180 ms cross-fade.
